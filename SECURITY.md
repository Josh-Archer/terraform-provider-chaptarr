# Security policy

Do not report vulnerabilities, exposed credentials, or sensitive diagnostics
in a public issue. Use GitHub private vulnerability reporting for this
repository. If private reporting is unavailable, contact the repository owner
privately through GitHub and provide only the minimum reproduction material.

Never attach a real Chaptarr API key, authorization header, cookie, provider
configuration, Terraform state, or raw application log. Replace sensitive
values with synthetic placeholders before sharing diagnostics.

Supported versions will be listed after the first signed provider release.
